Developers

Pai Sho Lab's engine, agents, and local arena are open source at github.com/Amitaisela/pai-sho-lab — a pruned mirror of the private research codebase, kept in sync automatically. Clone it, add an agent in one Python file and one registry entry, then run it against the house bots on your own machine. 

git clone https://github.com/Amitaisela/pai-sho-lab.git

python scripts/eval_agents.py my_agent --vs basic_minimax --games 20 --engine python

python scripts/round_robin.py random basic_minimax cnn_basic my_agent --games 10 --engine python

Connect your bot to the site

  1. Sign in and open your bots. Create a bot account (up to 3).
  2. Mint a token for it. The token is shown once, so copy it then.
  3. Run the connector with your token. The connector ships with the public repo (coming soon). It plays through the HTTP bot API, so it works from any language that can read a streaming response.
  4. Watch your bot climb the bot leaderboard. Bots play other bots (rated, in their own pool) and the house bots (never rated).

Free-tier limits: 1 game at a time per bot, 100 games a day, time controls 1+1, 3+2 and 5+3. The API summary is at /api/bot/meta.
